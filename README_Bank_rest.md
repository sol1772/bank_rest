### REST API Bank Card Management System (2026)

**Functionality:**  
Spring Security authentication and authorization.  
Role-based accessing the API using a JWT token.  
Admin: creates, activates, blocks and deletes cards, manages users, views all cards.  
User: views own cards (balance, etc.), sets a password, makes transfers between own cards, makes card-blocking
requests.  
Filtering and paginated search of users, cards, bank transactions, data encryption, masking card numbers.  
Error handling, validation of incoming data, Unit-tests, logging.

**Stack used:**  
JDK 21, REST API, Spring 6 (Boot 3, Data, Security, Web), JPA/Hibernate, Tomcat 10, PostgreSQL, JUnit 5, Maven, Git,
Docker, IntelliJIDEA.

### REST API Система управления банковскими картами (2026)

**Функционал:**  
Аутентификация и авторизация пользователей по логину и паролю с помощью Spring Security.  
Доступ на основе ролей к API с помощью JWT токена.  
Администратор: создает, активирует, блокирует и удаляет карты, управляет пользователями, просматривает все карты.
Пользователь: просматривает свои карты (баланс и т. д.), устанавливает пароль, совершает переводы между своими картами,
отправляет запросы на блокировку карт.
Фильтрация и постраничный поиск пользователей, карт, банковских транзакций, шифрование данных, маскировка номеров карт.
Обработка ошибок, валидация входящих данных, Unit-тестирование, логирование операций.

**Используемый стек:**  
JDK 21, REST API, Spring 6 (Boot 3, Data, Security, Web), JPA/Hibernate, Tomcat 10, PostgreSQL, JUnit 5, Maven, Git,
Docker, IntelliJIDEA.
